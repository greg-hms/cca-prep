# CCA-F Prep

Claude Certified Architect - Foundations exam preparation PWA.

13 courses, 156+ practice questions, and exam simulations.

## Features

- 13 study modules with flashcards
- Mini quizzes (10 questions per module)
- Training mode (60 questions, instant feedback)
- Exam simulation (60 questions, 120 min timer)
- Progress tracking and statistics
- 100% offline-capable (PWA)

## Stack

React + Vite + Tailwind v4 + Dexie (IndexedDB) + vite-plugin-pwa

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
